# מיפויים אזוריים — מרכז הידע גליל מזרחי־מערבי

מאגר זה מתעדכן אוטומטית ממאגר העבודה של מרכז הידע. **אין לערוך בו ישירות** —
כל שינוי יידרס בעדכון הבא.

## התוכן

| מיפוי | דף | נתונים |
|---|---|---|
| ארגונים העוסקים בפיתוח כלכלי בגליל המזרחי | `index.html` | `data/organizations.json` |
| ארגונים הפועלים עם צעירים בגליל | `young/index.html` | `data/young-organizations.json` |

כל דף הוא קובץ HTML עצמאי: הנתונים והלוגו מוטמעים בו, ואין בו תלות בקבצים
אחרים. קובצי ה-JSON מכילים בדיוק את הנתונים שמוצגים בדף, בפורמט נוח לקריאה
ממכונה — עדיף להשתמש בהם ולא לחלץ את הנתונים מה-HTML.

## מבנה קובצי הנתונים

```json
{
  "organizations": [ ... ],   // רשומה לכל ארגון
  "legend":        [ ... ],   // הסברים על המיפוי: {"topic", "text"}
  "tagOrder":      [ ... ]    // סדר התצוגה של התגיות
}
```

שדות של ארגון:

| שדה | תוכן |
|---|---|
| `id` | מזהה קבוע. `index.html#<id>` פותח את הכרטיס שלו |
| `name` | שם הארגון |
| `aliases` | שמות נוספים שבהם הוא מוכר |
| `type`, `typeGroup` | סוג הגוף, ומשפחת הסוג שלפיה מסננים (מיפוי הפיתוח הכלכלי בלבד) |
| `scope` | היקף הפעילות (למשל `גליל מזרחי`, `ארצי`) |
| `areaText` | מרחב הפעילות כטקסט חופשי |
| `places` | יישובים ואזורים שבהם הוא פועל |
| `tags` | תחומי פעילות |
| `audience` | אוכלוסיית יעד (מיפוי הצעירים בלבד) |
| `intro` | תיאור |
| `actions` | פעולות ותוכניות: `{"title", "body", "partners"}` |
| `partners` | כל השותפים שמוזכרים בפעולות |
| `note` | הערה |
| `website` | אתר |

שדה ריק פירושו שאין מידע, לא שהתשובה שלילית.

## פתיחה מסוננת

הדפים קוראים פרמטרים מה-URL:

```
index.html?scope=גליל מזרחי
index.html?tag=תעסוקה והשמות,הכשרות
index.html?place=קריית שמונה
index.html?q=חדשנות
```

## סייג

המיפוי משקף את המקורות שסופקו לו בתוספת אימות ממקורות פתוחים. זו אינה רשימה
ממצה של כלל הגופים הפועלים במרחב. המיפוי אינו כולל פרטי קשר של אנשים.
