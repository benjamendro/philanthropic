# מיפוי גופים לפיתוח כלכלי בגליל המזרחי

דף HTML יחיד ועצמאי המציג את המיפוי המאוחד של הגופים הפועלים בתחום הפיתוח
הכלכלי בגליל המזרחי. הדף מיועד לפרסום ב-GitHub Pages ולהטמעה כ-iframe
בפלטפורמת ArcGIS Experience.

**הדף החי:** `index.html` בשורש המאגר.

---

## מבנה המאגר

| נתיב | תפקיד |
|---|---|
| `index.html` | התוצר. קובץ אחד, ללא תלות חיצונית מלבד גופני Google Fonts. הלוגו והנתונים מוטמעים בתוכו. |
| `data/organizations.json` | הנתונים אחרי עיבוד — מקור האמת של הדף. |
| `tools/build_data.py` | בונה את ה-JSON מקובץ האקסל + שכבת העריכה. |
| `tools/build_site.py` | בונה את `index.html` מה-JSON + התבנית + הלוגו. |
| `tools/template.html` | תבנית הדף (HTML/CSS/JS). כאן עורכים עיצוב והתנהגות. |
| `tools/curation.py` | שכבת העריכה: תיקוני כתיב, קיצור ניסוחים, איחוד תגיות, השלמות. |
| `tools/additions.py` | ארגונים שנוספו מעבר לקובץ האקסל, על בסיס מקורות פתוחים. |
| `מיפוי מאוחד - ...xlsx` | קובץ המקור. |
| `young-organizations-dashboard/` | אתר קודם (מיפוי ארגוני צעירים) — נשמר כהתייחסות, לא חלק מהתוצר. |

## בנייה מחדש

```bash
pip install openpyxl pillow
python3 tools/build_data.py    # אקסל + שכבת עריכה  →  data/organizations.json
python3 tools/build_site.py    # JSON + תבנית + לוגו →  index.html
```

`pillow` משמש רק להקטנת הלוגו לפני ההטמעה. בלעדיו הבנייה עובדת, אבל הקובץ
יגדל מכ-180KB לכ-470KB.

### מה לערוך ואיפה

* **תוכן של ארגון קיים** — בקובץ האקסל, ואז `build_data.py`.
* **תיקון כתיב או ניסוח** — `tools/curation.py`, כדי שהתיקון לא יאבד בעדכון הבא של האקסל.
* **ארגון חדש** — `tools/additions.py`.
* **עיצוב, מסננים, טקסטים בממשק** — `tools/template.html`.

## פרסום ב-GitHub Pages

Settings → Pages → Source: `Deploy from a branch`, ענף `main`, תיקייה `/ (root)`.
הדף יהיה זמין בכתובת `https://<user>.github.io/<repo>/`.

## הטמעה ב-ArcGIS Experience

הדף עצמאי לחלוטין ואינו מנסה לתקשר עם המפה. יש להוסיף ווידג'ט Embed ולהצביע
על כתובת ה-Pages. הרקע לבן כדי שההטמעה תתמזג עם רקע ה-Experience.

הדף קורא פרמטרים מה-URL, כך שאפשר לפתוח אותו כשהוא כבר מסונן — שימושי אם
בהמשך תרצו לחבר אותו לבחירה במפה:

```
index.html?scope=מיקוד בגליל המזרחי
index.html?tag=תעסוקה והשמות,הכשרות
index.html?place=קריית שמונה
index.html?relevance=ליבה&q=חדשנות
index.html#<מזהה-ארגון>          פותח כרטיס מסוים
```

הפרמטרים הנתמכים: `q`, `relevance`, `type`, `scope`, `place`, `tag`
(מופרד בפסיקים).

## מה נעשה בנתונים

השכבה שב-`tools/` מתעדת כל התערבות בקובץ המקור:

* **תיקוני כתיב** — כ-25 תיקונים שמקורם בטופס שמולא ידנית (`השיקטל`→`השיקול`,
  `הביתה חזורים`→`חוזרים`, `הטשכנולוגיה`→`הטכנולוגיה` ועוד), ואיחוד כתיב
  (`שרות`→`שירות`, `איזור`→`אזור`).
* **קיצור ניסוחים** — ארבע רשומות נכתבו בסגנון שיווקי חורג (JNF-USA, שירות
  התעסוקה, מצפינים, מרכז לאודר). הוסרו מהן משפטי סיכום חוזרים ונשמר התוכן העובדתי.
* **איחוד תגיות** — שתי אוצרות מילים אוחדו לאחת (`תעסוקה`+`תעסוקה והשמות`,
  `צעירים`+`צעירים וסטודנטים` וכו'), ותוקן פיצול שגוי של
  `STEM (מדע, טכנולוגיה, הנדסה, מתמטיקה)` לארבע תגיות נפרדות.
* **השלמת תגיות** — 29 ארגונים הגיעו ממקורות שלא תוייגו. התגיות שלהם נגזרו
  מהתיאור ומסומנות בדף כהשלמה (מסגרת מקווקוות + הערה בתחתית הכרטיס).
* **איחוד סוגי גוף** — 42 ערכי טקסט חופשי קובצו לשמונה משפחות שניתן לסנן לפיהן.
* **הערות פנימיות** — אמירות על כשירות של צד שלישי ("ללא אישור ניהול תקין",
  "מומלץ לאמת שפעילה") נשמרות ב-JSON תחת `internalNote` ואינן מוצגות בדף.

## סייג

המיפוי משקף את המקורות שסופקו בתוספת אימות ממקורות פתוחים. אין זו רשימה ממצה
של כלל הגופים הפועלים במרחב.
