# מיפויים אזוריים — מרכז הידע גליל מזרחי־מערבי

דפי HTML עצמאיים המציגים מיפויים אזוריים, מיועדים לפרסום ב-GitHub Pages
ולהטמעה כ-iframe בפלטפורמת ArcGIS Experience.

| מיפוי | הדף | כלי העריכה | נתונים |
|---|---|---|---|
| פיתוח כלכלי בגליל המזרחי | `index.html` | `editor.html` | `data/organizations.json` |
| ארגונים הפועלים עם צעירים | `young/index.html` | `young/editor.html` | `data/young-organizations.json` |

שני המיפויים נבנים מאותן תבניות ומאותו צינור. הוספת מיפוי שלישי היא הוספת
קובץ נתונים והגדרה ב-`tools/sites.py`, בלי לגעת בקוד התצוגה.

---

## עדכון תוכן — הדרך הרגילה

1. פותחים את כלי העריכה של אותו מיפוי בדפדפן (הורדה מהמאגר ופתיחה מקומית,
   או דרך כתובת ה-Pages).
2. עורכים: שם, תיאור, תגיות, יישובים, פעולות, הערה, אתר. אפשר גם להוסיף
   ולמחוק ארגונים. העריכה נשמרת בדפדפן, כך שאפשר לעצור ולחזור.
3. לוחצים **ייצוא** ומקבלים `organizations.json` מעודכן.
4. מחליפים בו את קובץ הנתונים של אותו מיפוי בתיקיית `data/` (גרירה לתוך
   GitHub בדפדפן).
5. ה-Action `.github/workflows/publish.yml` בונה מחדש את כל הדפים ודוחף
   אותם. הדף מתעדכן בלי צעד נוסף.

כפתור **סיכום שינויים** מפיק רשימה קריאה של מה שהשתנה — נוח לשליחה לבדיקה
לפני העלאה.

העריכה ב-`editor.html` מתבצעת כולה בדפדפן ואינה משנה דבר בשרת. מי שיפתח
את הקובץ יוכל לשחק בעותק המקומי שלו בלבד; מה שמתפרסם נקבע אך ורק על ידי
מי שיש לו הרשאת כתיבה למאגר.

## מבנה המאגר

| נתיב | תפקיד |
|---|---|
| `data/*.json` | **מקור האמת** של כל מיפוי. |
| `tools/sites.py` | הגדרת המיפויים: כותרות, מסננים, מדדים, שדות עריכה. |
| `tools/build_site.py` | בונה את כל הדפים וכלי העריכה מקובצי הנתונים. |
| `tools/template.html` | תבנית הדף המפורסם, משותפת לכל המיפויים. |
| `tools/editor_template.html` | תבנית כלי העריכה, משותפת לכל המיפויים. |
| `tools/build_data.py` | ייבוא חד-פעמי של מיפוי הפיתוח הכלכלי מהאקסל. |
| `tools/curation.py` | שכבת העריכה שהופעלה בייבוא ההוא. |
| `tools/additions.py` | ארגונים שנוספו בייבוא ההוא מעבר לאקסל. |
| `tools/import_young.py` | ייבוא חד-פעמי של מיפוי הצעירים. |
| `.github/workflows/publish.yml` | בונה ודוחף אוטומטית בכל שינוי בנתונים. |
| `מיפוי מאוחד - ...xlsx` | קובץ המקור של מיפוי הפיתוח הכלכלי. |
| `young-organizations-dashboard/src/processed_data.json` | קובץ המקור של מיפוי הצעירים. **מכיל שמות אנשי קשר וטלפונים** — ראו אזהרה למטה. |

## בנייה ידנית

```bash
pip install pillow
python3 tools/build_site.py            # כל המיפויים
python3 tools/build_site.py young      # מיפוי אחד
```

`pillow` משמש רק להקטנת הלוגו לפני ההטמעה. בלעדיו הבנייה עובדת, אבל הקובץ
יגדל מכ-170KB לכ-460KB.

### שינוי עיצוב או התנהגות

`tools/template.html` לדף המפורסם, `tools/editor_template.html` לכלי העריכה,
ואז `build_site.py`.

### הוספת מיפוי חדש

1. קובץ נתונים ב-`data/`, במבנה של הקיימים.
2. ערך ב-`SITES` שב-`tools/sites.py`: נתיבים, כותרות, מסננים, מדדים ושדות עריכה.
3. `python3 tools/build_site.py`.

### אזהרה לגבי סקריפטי הייבוא

`build_data.py` ו-`import_young.py` מייבאים מקובצי המקור ודורסים את קובצי
ה-JSON. מרגע שעורכים דרך כלי העריכה, ה-JSON הוא מקור האמת, ולכן שניהם
מסרבים לרוץ כשהקובץ כבר קיים אלא אם מוסיפים `--force`.

### נתונים אישיים בקובץ המקור של מיפוי הצעירים

`young-organizations-dashboard/src/processed_data.json` מכיל 60 שמות של
אנשי קשר ו-56 מספרי טלפון נייד פרטיים. הם **אינם** מיובאים ואינם מופיעים
באף דף, אבל הקובץ עצמו נמצא במאגר. אם המאגר ציבורי, כדאי למחוק אותו לאחר
שהייבוא הושלם.

## פרסום ב-GitHub Pages

Settings → Pages → Source: `Deploy from a branch`, ענף `main`, תיקייה `/ (root)`.
הדף יהיה זמין בכתובת `https://<user>.github.io/<repo>/`.

## הטמעה ב-ArcGIS Experience

הדף עצמאי לחלוטין ואינו מנסה לתקשר עם המפה. יש להוסיף ווידג'ט Embed ולהצביע
על כתובת ה-Pages. הרקע לבן כדי שההטמעה תתמזג עם רקע ה-Experience.

הדף קורא פרמטרים מה-URL, כך שאפשר לפתוח אותו כשהוא כבר מסונן — שימושי אם
בהמשך תרצו לחבר אותו לבחירה במפה:

```
index.html?scope=גליל מזרחי
index.html?tag=תעסוקה והשמות,הכשרות
index.html?place=קריית שמונה
index.html?relevance=ליבה&q=חדשנות
index.html#<מזהה-ארגון>          פותח כרטיס מסוים
```

הפרמטרים הנתמכים: `q`, `relevance`, `type`, `scope`, `place`, `tag`
(מופרד בפסיקים).

## מה נעשה בנתונים

השכבה שב-`tools/` מתעדת כל התערבות בקובץ המקור:

שני עקרונות מנחים, שנקבעו על ידי המזמין:

1. **תוכן לא נמחק בגלל ניסוח.** גם רשומות שנכתבו בסגנון שיווקי מנופח נשארות
   כלשונן — מידע נוסף אינו גורע. אין בשכבת העריכה שום מחיקת תוכן.
2. **אין מפרסמים נתונים אישיים.** אין בדף טלפון, דוא"ל או איש קשר של אף גורם,
   ושמות של אנשים פרטיים שהופיעו בקובץ המקור כמצייני קשר הוסרו.

ומעבר לכך:

* **תיקוני כתיב** — כ-25 תיקונים שמקורם בטופס שמולא ידנית (`השיקטל`→`השיקול`,
  `הביתה חזורים`→`חוזרים`, `הטשכנולוגיה`→`הטכנולוגיה` ועוד), ואיחוד כתיב
  (`שרות`→`שירות`, `איזור`→`אזור`).
* **איחוד תגיות** — שתי אוצרות מילים אוחדו לאחת (`תעסוקה`+`תעסוקה והשמות`,
  `צעירים`+`צעירים וסטודנטים` וכו'), ותוקן פיצול שגוי של
  `STEM (מדע, טכנולוגיה, הנדסה, מתמטיקה)` לארבע תגיות נפרדות.
* **השלמת תגיות** — 29 ארגונים הגיעו ממקורות שלא תוייגו, והתגיות שלהם נגזרו
  מהתיאור. הסימון ב-JSON הוא `tagsDerived`.
* **איחוד סוגי גוף** — 42 ערכי טקסט חופשי קובצו לשמונה משפחות שניתן לסנן לפיהן.
* **שמות המקורות** — ארבעת קבצי המיפוי קובצו לשמות ציבוריים (מיפוי FronTech,
  מיפוי מרכז הידע גליל מזרחי ומערבי, גיידסטאר), ומהמקורות הפתוחים נשמרו
  כתובות אתרים בלבד. המקורות מוצגים כמשפט אחד בראש הדף ובתחתיתו, לא בכל כרטיס.
* **הסרת תוויות ויומן עבודה** — התווית `מטרות רשומות:` הוסרה מ-17 תיאורים,
  ו-18 הערות שתיארו כיצד הורכב המיפוי הועברו ל-`internalNote`.
* **גיאוגרפיה** — מסנן היישובים כולל רק מקומות בתוך הגליל המזרחי. גוף שפועל
  גם מחוץ לאזור נשאר במיפוי, אך המקומות הרחוקים אינם נמנים.
* **הערות פנימיות** — אמירות על כשירות של צד שלישי ("ללא אישור ניהול תקין",
  "מומלץ לאמת שפעילה") נשמרות ב-JSON תחת `internalNote` ואינן מוצגות בדף.

## סייג

המיפוי משקף את המקורות שסופקו בתוספת אימות ממקורות פתוחים. אין זו רשימה ממצה
של כלל הגופים הפועלים במרחב.
